# 井字棋 Cjing 0.2.0 分发包

| 文件 | 平台 | 签名状态 | 说明 |
|---|---|---|---|
| `Cjing-0.2.0-android.apk` | Android | 调试证书（可直装） | arm64-v8a + x86_64 |
| `Cjing-0.2.0-ios-unsigned.ipa` | iOS | **未签名** | 需自行签名后才能安装 |
| `Cjing-0.2.0-ohos-unsigned.hap` | HarmonyOS | **未签名** | 需自行签名后才能安装 |
| `Cjing-0.2.0-macos-universal.zip` | macOS | ad-hoc 签名 | Universal（arm64 + x86_64） |

---

## Android

直接安装（允许"未知来源"）：

```bash
adb install -r Cjing-0.2.0-android.apk
```

或拷到手机后用文件管理器打开（部分国产 ROM 需先开"USB 安装/未知来源"）。

---

## iOS（未签名 IPA，需自签）

IPA 里是 `Payload/cjing.app`，**没有签名**，必须用你自己的 Apple ID 重签：

| 工具 | 说明 |
|---|---|
| **Sideloadly / AltStore / SideStore** | 图形化，免费 Apple ID 可用（7 天有效） |
| **Xcode** | 新建同名工程太麻烦；建议用 sideload 工具 |
| **企业/开发者证书** | 用 `codesign` + 自己的 `.mobileprovision` 重签 |

包名 `com.timelightspeed.cjing`，重签时可改成你自己的 Bundle ID。
免费账号签名 **7 天过期**，到期重签即可。

---

## HarmonyOS（未签名 HAP，需自签）

未签名 HAP 无法安装到真机（`no signature file`）。用 DevEco 或 `hap-sign-tool` 重签：

1. DevEco 打开任意鸿蒙工程（或本仓库 `platform_ohos/app`），*Project Structure → Signing Configs* 生成调试证书与 Profile
2. 把 `Cjing-0.2.0-ohos-unsigned.hap` 用该证书签名（Profile 的 `bundle-name` 需匹配 `com.timelightspeed.cjing`，调试 Profile 需包含目标设备 UDID）
3. `hdc install -r <signed.hap>`

> 最省事的方式：直接在本仓库执行
> `./scripts/ohos-build.sh --signing <你的本地签名配置>` 生成签名包。

---

## macOS

解压后得到 `Cjing.app`，已做 ad-hoc 签名（Apple Silicon 必需）。

首次打开会被 Gatekeeper 拦截：

- 右键 → 打开 → 仍要打开；或
- 终端执行：`xattr -dr com.apple.quarantine Cjing.app`

支持 macOS 12+，Universal（Apple Silicon / Intel）。

---

## Windows / Linux

本机（macOS）无法交叉编译，改由 GitHub Actions 产出：

1. 打开仓库 Actions → **分发包（桌面三平台）** → *Run workflow*
2. 跑完后在该次运行页底部下载：
   - `Cjing-linux`（`.tar.gz`）
   - `Cjing-windows`（`.zip`）
   - `Cjing-macos`（`.zip` + `.dmg`）
3. 解压即用（SDL 已静态链接，无需额外 DLL/.so）

Windows 首次运行可能触发 SmartScreen：*更多信息 → 仍要运行*。
Linux 需要图形会话（X11 或 Wayland）。
