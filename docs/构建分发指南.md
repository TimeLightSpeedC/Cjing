# 构建与分发指南（0.2.0）

> 本文覆盖：**鸿蒙 HAP 为什么大**、三台机器（macOS 本机 / Win10 笔记本 / WSL）各自怎么构建、
> 以及各平台交付物如何验证。

---

## 一、为什么鸿蒙 HAP 比其它平台大很多

实测 `Cjing-0.2.0-ohos-unsigned.hap` = **27.34 MiB**，构成：

| 内容 | 体积 |
|---|---|
| `libs/`（两个 ABI 的 SDL3 / SDL3_ttf / libc++ / libmain） | **17.07 MiB** |
| `resources/rawfile/`（字体 10.07 + 音效） | **10.14 MiB** |
| `ets/` 及其它 | 0.12 MiB |

三个原因：

1. **同时打两个 ABI**：`arm64-v8a` + `x86_64`，各带一份完整原生库。
   x86_64 那份约 **8.6 MiB**，对真机完全是冗余。
2. **HAP 对 `.so` 与 `rawfile` 一律不压缩（store）**：
   10.07 MiB 的 NotoSansSC 字体原样存放。
   而 APK/IPA/ZIP 都是压缩包，同一字体压完只剩 ~2–3 MiB。
3. **SDL3_ttf 内置 FreeType + HarfBuzz**，每个 ABI 约 4 MiB（已 strip）。

### 可选的优化（按收益排序）

| 措施 | 收益 | 代价 |
|---|---|---|
| **字体子集化**（只保留用到的几十个字） | HAP 约 −10 MiB，**所有平台都受益** | 需要新增字符时重新生成 |
| 发布版 `abiFilters` 只留 `arm64-v8a` | HAP 约 −8.6 MiB | x86_64 模拟器不能装 |
| 维持现状 | — | 27 MiB |

> 字体子集化是唯一"全平台通吃"的优化，建议列入 P5。

## 二、三台机器的分工

| 机器 | 负责产出 |
|---|---|
| **本机 macOS** | Android APK、macOS `.pkg`/`.dmg`、iOS 未签名 IPA、鸿蒙未签名 HAP |
| **Win10 笔记本** | Windows 安装程序 `.exe`（Inno Setup） |
| **笔记本上的 WSL（Ubuntu）** | GNU/Linux AppImage |

## 三、本机 macOS

### 3.0 前置

- Xcode Command Line Tools：`xcode-select --install`
- CMake 3.21+（或沿用 CLion 自带的 cmake，脚本会自动找）
- Android Studio（提供 SDK + JBR）
- DevEco Studio（提供鸿蒙 SDK/hvigor）

### 3.1 Android release APK

```bash
cd ~/Desktop/MacMiniTest/Cjing
./scripts/package-android.sh
```

- 默认用 `~/.android/debug.keystore` 签名（可直装）
- 正式签名：

```bash
CJING_ANDROID_KEYSTORE=~/my.jks \
CJING_ANDROID_KS_PASS=**** \
CJING_ANDROID_KEY_ALIAS=key \
CJING_ANDROID_KEY_PASS=**** \
./scripts/package-android.sh
```

产物：`dist/Cjing-0.2.0-android.apk`

### 3.2 macOS 安装包

```bash
./scripts/package-macos-installer.sh
```

- 产物：`dist/Cjing-0.2.0-macos.pkg`（安装到 `/Applications`）
- 同一脚本会尝试生成 `.dmg`；**在受限终端里挂载磁盘卷会失败**，
  用普通终端重跑即可，或用：

```bash
hdiutil create -volname Cjing -srcfolder dist/Cjing.app -ov -format UDZO \
  dist/Cjing-0.2.0-macos-universal.dmg
```

> `.pkg` 与 `.app` 都只做了 ad-hoc 签名，未做 Developer ID 签名/公证；
> 收件人需在「隐私与安全性」放行。

### 3.3 iOS 未签名 IPA

```bash
CM=$(command -v cmake || echo /Applications/CLion.app/Contents/bin/cmake/mac/aarch64/bin/cmake)
NINJA=$(command -v ninja || echo /Applications/CLion.app/Contents/bin/ninja/mac/aarch64/ninja)

"$CM" -S ios -B build-ios-device -G Ninja -DCMAKE_MAKE_PROGRAM="$NINJA" \
  -DCMAKE_SYSTEM_NAME=iOS -DCMAKE_OSX_SYSROOT=iphoneos \
  -DCMAKE_OSX_ARCHITECTURES=arm64 -DCMAKE_OSX_DEPLOYMENT_TARGET=16.0 \
  -DBUILD_SHARED_LIBS=OFF -DCMAKE_BUILD_TYPE=Release
"$CM" --build build-ios-device --parallel 8

rm -rf /tmp/ipa && mkdir -p /tmp/ipa/Payload
cp -R build-ios-device/cjing.app /tmp/ipa/Payload/
(cd /tmp/ipa && zip -qry ../../dist/Cjing-0.2.0-ios-unsigned.ipa Payload)
```

### 3.4 鸿蒙未签名 HAP

```bash
./scripts/ohos-build.sh          # 未配置签名时产出 unsigned
```

产物：`platform_ohos/app/entry/build/default/outputs/default/entry-default-unsigned.hap`

## 四、Windows 10 笔记本

### 4.1 安装工具

1. **Visual Studio 2022 Community** → 勾选「使用 C++ 的桌面开发」
2. **CMake**（安装时勾选 *Add CMake to the system PATH*）
3. **Inno Setup 6**（<https://jrsoftware.org/isdl.php>）
4. **Git for Windows**

### 4.2 克隆与构建

```powershell
git clone https://github.com/TimeLightSpeedC/Cjing.git
cd Cjing
powershell -ExecutionPolicy Bypass -File scripts\package-windows.ps1
```

- 首次构建会通过 CMake FetchContent 拉取 SDL3 / SDL3_ttf（需联网，几分钟）
- 静态链接，产物不依赖 DLL

### 4.3 产物

```
dist\Cjing-0.2.0-windows-setup.exe   ← Inno Setup 安装程序
```

若未装 Inno Setup，脚本回退为 `Cjing-0.2.0-windows-x64.zip`（便携版）。

> 安装程序与 exe 均未做代码签名，SmartScreen 会提示
> 「更多信息 → 仍要运行」。

## 五、WSL（Windows 笔记本上的 Ubuntu）

### 5.1 一次性准备

```powershell
wsl --install -d Ubuntu
```

进入 Ubuntu 后安装依赖：

```bash
sudo apt-get update
sudo apt-get install -y build-essential cmake ninja-build curl file git \
  libx11-dev libxext-dev libxrandr-dev libxcursor-dev libxi-dev \
  libxfixes-dev libxss-dev libxtst-dev libwayland-dev libdecor-0-dev \
  libfribidi-dev libasound2-dev libpulse-dev libdbus-1-dev \
  libibus-1.0-dev libudev-dev libunwind-dev
```

> 仓库放在 WSL 自己的文件系统里（如 `~/Cjing`），不要放 `/mnt/c`，否则编译很慢。

### 5.2 构建 AppImage

```bash
git clone https://github.com/TimeLightSpeedC/Cjing.git ~/Cjing
cd ~/Cjing
./scripts/package-linux-appimage.sh
```

- 首次运行会下载 `appimagetool` 到 `.tools/`
- 产物：`dist/Cjing-0.2.0-linux-x86_64.AppImage`

### 5.3 拿到 Windows 上

```bash
cp dist/Cjing-0.2.0-linux-x86_64.AppImage /mnt/c/Users/<你的用户名>/Desktop/
```

AppImage 在真实 Linux 桌面运行；部分发行版需要 `libfuse2`
（或设置 `APPIMAGE_EXTRACT_AND_RUN=1`）。

## 六、验证清单

| 产物 | 验证方式 |
|---|---|
| Android APK | `adb install -r`，冷启动、落子、音效 |
| iOS IPA | 用 Sideloadly/AltStore 自签后安装 |
| 鸿蒙 HAP | 用自己证书签名后 `hdc install` |
| macOS `.pkg` | 双击安装 → `/Applications/井字棋.app` 启动 |
| Windows setup | 双击安装 → 开始菜单启动 |
| AppImage | `chmod +x` 后直接运行 |

完整性校验：

```bash
shasum -a 256 -c dist/SHA256SUMS
```

## 七、GitHub Actions 自动构建（可选）

仓库已带 `.github/workflows/release.yml`：

- 手动触发：Actions → 「分发包（桌面三平台）」→ Run workflow
- 或推送 `v*` 标签

三平台 runner 会各自产出安装包并上传 artifacts（Windows 走 Inno Setup，若 runner 未预装则回退 zip）。
